# IZ2S Platform 0.16.0-rc.3

Linux prerelease with a downloadable installation archive.

- File Exchange is the only bundled application module.
- IZMYSH is the only preinstalled engine. Two original engine adapters retain explicit download/manual installation.
- Add the optional console stream-menu contribution API used by VacooTube 1.4.0; applications remain separate packages.
- Update panel/shell release metadata and publish explicit Linux-only host support.

The existing installer, ARM input bundle and private-data exclusions are retained.
See SUPPORT.md, FAQ.md, LICENSE and THIRD_PARTY.json for setup and licensing details.

- Limit the connection menu to three engine choices.
